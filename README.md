# Revision Director

Revision Director is an offline-first revision planner and retrieval runner for long-horizon examinations. It schedules memory recall, concept reconstruction, application practice, performance practice, freshness review and corrective relearning, then builds capacity-aware daily revision plans from those obligations.

The current application identity is `va7.1-pass-f1`. It is a **clean-slate prototype**: there is intentionally no migration or backward-data compatibility layer. Current database, backup and FSRS contracts are strict; unsupported older shapes are rejected rather than transformed.

## Run

Open or deploy `index.html`.

The production artifact is self-contained: application code, CSS, presentation metadata and the vendored `ts-fsrs@6.0.0` browser runtime are embedded locally. No CDN, runtime package manager, framework or network-loaded application asset is required.

## Development

Required toolchain:

- Node.js 26.13.0
- npm 11.20.0
- TypeScript 7.0.2

Install and build:

```sh
npm ci
npm run build
```

`source/` is authoritative. `dist/app.js` and `index.html` are generated by `build/build.py`; do not edit generated artifacts by hand.

The root `index.html` deliberately remains the lean self-contained/offline distribution. To enable fully local in-browser FSRS-7 optimization, install the isolated optimizer dependencies and build the optional static distribution:

```sh
npm ci --prefix tools/fsrs-optimizer
npm run build:optimizer-static
```

Serve `Revision_Director_Optimizer_Static/` over localhost or HTTPS. Optimization runs in a dedicated local Worker/WASM runtime, reports progress, is cancellable, and only stages a profile; activation remains a separate explicit action.
